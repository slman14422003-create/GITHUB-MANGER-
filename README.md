# GHManager (GitHub Manager for Android)

**GHManager** is a native, feature-rich Android application designed to give developers full control over their GitHub repositories, CI/CD workflows, file editing, issue tracking, and release management directly from a mobile device.

---

## 🌟 Key Features

### 📁 Repository & File Management
* **Repository Browsing**: Easily search, list, filter, and inspect public and private GitHub repositories.
* **In-App Code Editor & Viewer**: Browse file trees, open code files, and edit source code on the go using an integrated text/code editor.
* **File Operations & Scanner**: Built-in file scanner and manager to inspect, edit, and push changes directly back to your repositories.
* **Branch & Commit History**: Switch between branches, review commit logs, and inspect changes made across revisions.

### ⚙️ GitHub Actions & CI/CD Pipelines
* **Workflow Automation**: View and monitor all active GitHub Actions workflows.
* **Manual Workflow Dispatch**: Trigger workflows manually with custom inputs directly from the app (`WorkflowInputs`).
* **Run Details & Log Viewer**: Inspect execution logs, check run statuses, and analyze build output step-by-step.
* **Artifact Management**: View and manage build artifacts generated by your GitHub Actions workflows.

### 🐛 Issue Tracking & Management
* **Issue Dashboard**: Filter, search, and view issues across repositories.
* **Detailed Issue Interactions**: Create new issues, comment, edit details, and modify issue statuses or labels.

### 📦 Releases & Assets
* **Release Management**: Track published releases and tag histories.
* **Asset Downloads**: Download release binaries, source archives, and attached assets directly to your device.

### 👥 Permissions & Collaborators
* **Collaborator Overview**: Manage repository access, collaborators, and permission tiers (`PermissionsActivity`).
* **Security & Insights**: Access repository insights, traffic metrics, and security overview.

### 🔒 Security & Privacy
* **Secure Token Storage**: Encrypted credential and token management powered by `SealedBox` cryptography.
* **Custom Keystore Generation**: Automated scripts and GitHub workflows for keystore generation and secure APK signing.
* **Network Security Configuration**: Strict network security rules and data extraction protection policies.

### 🛠️ User Interface & Customization
* **Dark Mode & Themes**: Full support for system-wide light and dark themes.
* **In-App Browser & Logs**: Integrated lightweight web browser for external GitHub pages and an in-app log viewer (`LogActivity`) for debugging.
* **In-App Self Updater**: Built-in update engine (`Updater`) to notify and apply app updates seamlessly.
* **Multi-language Support**: Multi-lingual UI support including English localization.

## 🏗️ Architecture & Project Structure

The project follows standard Android native development conventions written in **Java** and built using **Gradle**:

```text
GITHUB-MANGER/
├── .github/workflows/       # GitHub Actions CI/CD workflows (Build & Keystore generation)
├── app/
│   ├── src/main/java/com/ghmanager/app/
│   │   ├── ActionsActivity.java       # Workflow & CI/CD management
│   │   ├── EditorActivity.java        # Code/file editing activity
│   │   ├── FileManagerActivity.java   # Repository file explorer
│   │   ├── GitHubApi.java             # GitHub REST & GraphQL API client
│   │   ├── IssuesActivity.java        # Issue tracking
│   │   ├── SealedBox.java             # Encryption & security layer
│   │   └── Updater.java               # Automatic app update checking
│   └── src/main/res/                  # Layouts, drawables, strings & themes
├── tools/                         # Maintenance shell scripts (e.g., make-keystore.sh)
└── build.gradle                   # Root build configuration
```

## 🚀 Getting Started

### Prerequisites
* **Android Studio**: Jellyfish or newer recommended.
* **JDK**: Java Development Kit 17 or higher.
* **Android SDK**: API Level 34 (Android 14) or above.

### Building from Source

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/GITHUB-MANGER.git
   cd GITHUB-MANGER
   ```

2. **Generate Keystore (Optional for signed builds)**:
   You can run the included shell script to generate a release signing key:
   ```bash
   chmod +x tools/make-keystore.sh
   ./tools/make-keystore.sh
   ```

3. **Build the APK**:
   ```bash
   ./gradlew assembleRelease
   ```
   The compiled APK file will be available under `app/build/outputs/apk/release/`.

## 🔑 Authentication

GHManager requires a **GitHub Personal Access Token (PAT)** or OAuth login with appropriate scopes (`repo`, `workflow`, `write:packages`, `read:user`) to interact with your repositories and perform actions.
