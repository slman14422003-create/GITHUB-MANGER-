# GitHub Manager

Безопасное использование и защита от злоупотреблений: [SAFE_USE.md](SAFE_USE.md)

GitHub Manager это нативное Android-приложение (Java) для управления репозиториями GitHub, файлами, рабочими процессами Actions, issues и релизами с телефона.

## Возможности

Репозитории и файлы
- Список, поиск и фильтрация репозиториев, очистка старых.
- Загрузка целых папок с телефона с сохранением структуры. Приложение пропускает идентичные файлы, учитывает .gitignore, показывает предпросмотр (новые, изменённые, идентичные) перед загрузкой и продолжает после сбоя.
- Скачивание файлов, папок и целых репозиториев с паузой, возобновлением и отменой. Передачи продолжаются в фоне с уведомлением.
- Файловый менеджер устройства со списком и сеткой, множественным выбором перетаскиванием, поиском и встроенной корзиной, которая очищается сама через 30 дней.
- Редактор кода с подсветкой синтаксиса, номерами строк, отменой и повтором, поиском по коду, просмотром Markdown и построчным сравнением.

Ветки и коммиты
- Создание, слияние и удаление веток, выбор ветки по умолчанию.
- История коммитов и различия каждого коммита.

GitHub Actions
- Список workflow и просмотр запусков в реальном времени: каждое задание (job), каждый шаг и таймер.
- Просмотр логов с группировкой по шагам, номерами строк и фильтром только ошибок.
- Ручной запуск workflow с входными параметрами и очистка старых запусков.
- Скачивание артефактов с автоматическим извлечением APK.
- Сборка и публикация релиза с одного экрана.
- SEMO AI: автономная предварительная проверка перед запуском workflow. Находит несбалансированные скобки и безопасные ошибки форматирования и исправляет только то, в чём уверена. Не обращается к сети и не использует модель.

Issues, релизы и совместная работа
- Issues: просмотр, фильтрация, создание, комментарии и редактирование.
- Релизы: просмотр, публикация, удаление и скачивание файлов релиза.
- Соавторы: приглашение людей и изменение уровня доступа.
- Статистика репозитория: языки, трафик и участники.
- Настройки безопасности репозитория: защита веток, сканирование секретов, защита при push, обновления безопасности Dependabot и права Actions по умолчанию.
- Зашифрованные секреты Actions и настройка ключа подписи.

Безопасность и конфиденциальность
- Токен доступа хранится в Android Keystore.
- Необязательная блокировка приложения отпечатком, графическим ключом или PIN-кодом телефона.
- Снимки экрана внутри приложения по умолчанию запрещены; разрешить их можно в Настройки, Безопасность.
- Только HTTPS, доверяются только системные сертификаты. Резервное копирование отключено.
- APK можно запечатать при сборке, приложение проверяет печать при запуске.
- Обновления проверяются по SHA-256 и сертификату подписи.

Прочее
- Необязательное зеркало через Cloudflare Worker для сетей, где GitHub медленный или заблокирован.
- Интерфейс на арабском и английском, светлая и тёмная темы, несколько аккаунтов.

## Активация

1. Установка APK
   - Скачайте APK на странице Releases этого репозитория и установите. Разрешите "Установку неизвестных приложений" для программы, из которой открыли файл.
   - Требуется Android 7.0 (API 24) или новее.

2. Вход (выберите один способ)
   - Device flow: выберите вариант Google или e-mail, GitHub покажет код, введите его на официальной странице GitHub. Пароль никогда не проходит через приложение. Нужен GitHub OAuth App с включённым Device Flow; его Client ID по замыслу публичный. Укажите его в переменной репозитория GH_OAUTH_CLIENT_ID (Settings, Secrets and variables, Actions, Variables) до сборки или введите в приложении через пункт Client ID.
   - Персональный токен доступа: создайте токен на GitHub и вставьте в приложение. Давайте только нужные права. Device flow запрашивает: repo, workflow, delete_repo, read:org, user, admin:public_key.

3. Дополнительная защита
   - Настройки, Блокировка приложения: включите и выберите задержку. На телефоне уже должна быть настроена блокировка экрана.

## Сборка из исходников через GitHub Actions

1. Создайте постоянный ключ подписи. Запускайте workflow "Generate signing key" только в ЧАСТНОЙ копии репозитория; в публичном он отказывается работать. Скачайте артефакт, сохраните файлы офлайн в надёжном месте и удалите артефакт. Можно также запустить tools/make-keystore.sh на своём компьютере.
2. Добавьте секреты репозитория: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.
3. Запустите workflow "Build APK". Релиз появится на странице Releases.
4. Никогда не загружайте keystore, пароли или токены в репозиторий.

## Развёртывание Cloudflare Worker (необязательно)

Worker пересылает запросы только на хосты GitHub и отклоняет любой запрос без вашего секретного ключа.

1. Установите Node.js и откройте терминал в папке worker.
2. Вход: npx wrangler login
3. Развёртывание: npx wrangler deploy
4. Создайте длинный случайный ключ: openssl rand -hex 32
5. Сохраните его как секрет: npx wrangler secret put MIRROR_KEY и вставьте ключ. Без этого секрета Worker отвечает 503 на всё.
6. В приложении откройте Настройки, Зеркало (Mirror). Введите адрес Worker и ключ, нажмите Проверить.
7. Рекомендуется: в панели Cloudflare отключите адрес workers.dev, используйте свой домен и добавьте правило ограничения частоты запросов. Включите двухфакторную аутентификацию в аккаунте Cloudflare.
8. Если ключ раскрыт, немедленно замените его той же командой.
