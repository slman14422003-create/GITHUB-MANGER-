GitHub Manager تطبيق أندرويد أصلي (Java) لإدارة مستودعات GitHub والملفات وسير عمل Actions والمشاكل (Issues) والإصدارات من الهاتف.

## الميزات

المستودعات والملفات
- عرض المستودعات والبحث فيها وتصفيتها وتنظيف القديم منها.
- رفع مجلدات كاملة من الهاتف مع الحفاظ على بنيتها. يتخطى التطبيق الملفات المطابقة، ويحترم ملف .gitignore، ويعرض معاينة (جديد، متغيّر، مطابق) قبل الرفع، ويستأنف الرفع بعد أي فشل.
- تحميل ملفات أو مجلدات أو مستودعات كاملة مع إيقاف مؤقت واستئناف وإلغاء. تستمر العمليات في الخلفية مع إشعار.
- مدير ملفات للجهاز بعرض قائمة وشبكة، وتحديد متعدد بالسحب، وبحث، وسلة داخل التطبيق تُفرَّغ تلقائياً بعد 30 يوماً.
- محرر أكواد مع تلوين الصياغة وأرقام الأسطر والتراجع والإعادة والبحث في الأكواد وعرض Markdown وعرض الفروقات بين الأسطر.

الفروع والـ Commits
- إنشاء الفروع ودمجها وحذفها وتعيين الفرع الافتراضي.
- تصفح سجل الـ Commits وعرض فروقات كل Commit.

GitHub Actions
- عرض سير العمل ومتابعة التشغيلات مباشرة مع كل مرحلة وخطوة وعدّاد زمن.
- عارض سجلات بتجميع الخطوات وأرقام الأسطر وفلتر الأخطاء فقط.
- تشغيل سير عمل يدوياً مع مدخلات، وتنظيف التشغيلات القديمة.
- تحميل الـ Artifacts مع استخراج APK تلقائياً.
- بناء ونشر إصدار من شاشة واحدة.
- SEMO AI: فحص مسبق بدون اتصال يعمل قبل بدء سير العمل. يكتشف الأقواس غير المتوازنة وأخطاء التنسيق الآمنة ويصلح ما هو مؤكد فقط. لا يجري أي اتصال بالشبكة ولا يستخدم أي نموذج.

المشاكل والإصدارات والتعاون
- Issues: عرض وتصفية وإنشاء وتعليق وتعديل.
- الإصدارات: عرض ونشر وحذف وتحميل ملفات الإصدار.
- المتعاونون: دعوة أشخاص وتغيير مستوى صلاحيتهم.
- إحصاءات المستودع: اللغات وحركة الزيارات والمساهمون.
- إعدادات أمان المستودع: حماية الفروع وفحص الأسرار وحماية الدفع وتحديثات Dependabot الأمنية وصلاحيات Actions الافتراضية.
- أسرار Actions المشفّرة وإعداد مفتاح التوقيع.

الأمان والخصوصية
- يُخزَّن رمز الوصول عبر Android Keystore.
- قفل اختياري للتطبيق ببصمة الهاتف أو النمط أو الرقم السري.
- منع لقطة الشاشة داخل التطبيق افتراضياً، ويمكن إيقافه من الإعدادات ثم الأمان.
- اتصال HTTPS فقط ويثق بشهادات النظام فقط. النسخ الاحتياطي معطّل.
- يمكن ختم الـ APK وقت البناء، ويتحقق التطبيق من الختم عند التشغيل.
- تُتحقق تحديثات التطبيق بـ SHA-256 وبشهادة التوقيع.

أخرى
- وسيط (Mirror) اختياري عبر Cloudflare Worker للشبكات التي يكون فيها GitHub بطيئاً أو محجوباً.
- واجهة عربية وإنجليزية، وسمات فاتحة وداكنة، وحسابات متعددة.

## التفعيل

1. تثبيت التطبيق
   - نزّل ملف APK من صفحة Releases في هذا المستودع وثبّته. فعّل خيار "تثبيت التطبيقات غير المعروفة" للتطبيق الذي فتحت منه الملف.
   - يتطلب أندرويد 7.0 (API 24) أو أحدث.

2. تسجيل الدخول (اختر طريقة واحدة)
   - Device Flow: اضغط خيار Google أو البريد، يعرض GitHub رمزاً، أدخله في صفحة GitHub الرسمية. كلمة المرور لا تمر عبر التطبيق. يحتاج هذا إلى OAuth App في GitHub مع تفعيل Device Flow، ومعرّفه (Client ID) عام بطبيعته. ضعه في متغير المستودع GH_OAUTH_CLIENT_ID (Settings ثم Secrets and variables ثم Actions ثم Variables) قبل البناء، أو أدخله داخل التطبيق من خيار ضبط Client ID.
   - رمز وصول شخصي (PAT): أنشئ رمزاً في GitHub والصقه في التطبيق. أعطه الصلاحيات التي تحتاجها فقط. يطلب Device Flow الصلاحيات: repo وworkflow وdelete_repo وread:org وuser وadmin:public_key.

3. حماية اختيارية
   - الإعدادات ثم قفل التطبيق: فعّله واختر مدة القفل. يجب أن يكون قفل الشاشة مفعّلاً في الهاتف مسبقاً.

## البناء من المصدر عبر GitHub Actions

1. أنشئ مفتاح توقيع دائماً. شغّل سير العمل "Generate signing key" في نسخة خاصة (Private) من المستودع فقط، فهو يرفض العمل في مستودع عام. نزّل الـ Artifact واحفظ الملفين في مكان آمن بعيداً عن الإنترنت ثم احذف الـ Artifact. أو شغّل tools/make-keystore.sh على جهازك.
2. أضف أسرار المستودع: KEYSTORE_BASE64 وKEYSTORE_PASSWORD وKEY_ALIAS وKEY_PASSWORD.
3. شغّل سير العمل "Build APK". يظهر الإصدار في صفحة Releases.
4. لا ترفع ملف المفتاح أو كلمات المرور أو الرموز إلى المستودع أبداً.

## نشر Cloudflare Worker (اختياري)

يمرّر الـ Worker الطلبات إلى مضيفات GitHub فقط، ويرفض كل طلب لا يحمل مفتاحك السري.

1. ثبّت Node.js وافتح الطرفية داخل مجلد worker.
2. سجّل الدخول: npx wrangler login
3. انشر: npx wrangler deploy
4. أنشئ مفتاحاً عشوائياً طويلاً: openssl rand -hex 32
5. احفظه كسرّ: npx wrangler secret put MIRROR_KEY ثم الصق المفتاح. بدون هذا السرّ يرد الـ Worker على كل شيء بالخطأ 503.
6. في التطبيق افتح الإعدادات ثم المرآة (Mirror). أدخل عنوان الـ Worker والمفتاح ثم اضغط اختبار.
7. موصى به: من لوحة Cloudflare عطّل عنوان workers.dev واستخدم نطاقك الخاص، وأضف قاعدة تحديد معدل الطلبات. فعّل التحقق بخطوتين في حساب Cloudflare.
8. إذا انكشف المفتاح فغيّره فوراً بالأمر نفسه.
